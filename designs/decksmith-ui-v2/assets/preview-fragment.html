如何使用

  1. 点击上方的"查看设计"按钮，可以直接在浏览器中预览各个页面
  2. 所有页面都是静态 HTML 文件，不依赖后端服务
  3. 设计使用了统一的 Design Tokens，确保视觉一致性
  4. 支持响应式设计，可以在不同屏幕尺寸下查看效果
  5. 如需修改设计，可以直接编辑对应的 HTML 文件
