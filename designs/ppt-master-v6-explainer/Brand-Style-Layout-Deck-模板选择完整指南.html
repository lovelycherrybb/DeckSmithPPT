how to use / not just definitions

模板选择，不是选风格。
是决定“要复用什么”。

Brand、Style、Layout、Deck 是四块可以拆开、也可以拼起来的可复用工作区。先判断你想复用身份、方法、骨架还是整类演示，再选择模板，最后把精确路径交给 Generate。

最容易误解的一句话：“瑞士极简风”是单次生成的视觉参数；Style 模板工作区是可复用的方法和方向包，两者不是一回事。
official template application example
Brand + Layout 的典型结果：身份来自品牌工作区，页面骨架来自结构工作区。
01 / four reusable workspaces

四块模板，各管一件事

它们不是四种 PPT 文件，而是四类规则包。可以单独用，也可以组合。

01 / BRAND

身份真值

颜色、字体、Logo、voice、icon style。它决定“这像谁”。

identity
02 / STYLE

方法与方向

沟通方法、页面角色、证据表达、视觉默认值、图片方向。它决定“怎么讲”。

method
03 / LAYOUT

页面骨架

画布、page types、语义文字角色、slot、Master/Layout/Placeholder。它决定“怎么排”。

structure
04 / DECK

整类演示

重复场景、受众、结果、叙事、身份、结构、原型。它决定“哪一类汇报”。

application
02 / choose by goal

先看你要复用什么

选模板的起点不是“喜欢什么风”，而是“什么规则需要跨项目重复”。

recommended workspace / brand

只选 Brand

如果你只需要统一品牌身份，就选一个 Brand 工作区。页面仍然自由编排，不会自动获得固定页面结构。

03 / workspace assembly

拼出你的模板组合

每个 kind 可选一个工作区，也可以留空。右侧会生成一句可直接交给 PPT Master 的请求。

generated request

当前没有选择模板工作区。PPT Master 会按内容自由设计页面。


            
          

        

      

    


    

      

        

          
04 / complete workflow
完整使用流程

          
模板选择发生在 Generate 的规划阶段。不是生成完 PPT 后再贴皮肤。

        

        

          

            
            
            
            
            
            
          

          

            
先决定你想复用什么
DECIDE

            
模板选择的第一步不是选文件，而是判断哪些规则值得跨项目重复。只想要品牌一致，就选 Brand；想统一论证和证据表达，就选 Style；想复用页面骨架，就选 Layout。
  • 问自己：未来还会重复哪类演示？
  • 问自己：哪些值必须固定，哪些只是本次偏好？
  • 把“风格描述”转换成明确的 workspace 类型。

          

        

      

    


    

      

        

          
05 / common mistakes
三种最常见的选错

          
这三组对照能帮你把“感觉像模板”的说法，落到真正可执行的工作区。

        

        

          
wrong / 01
把视觉风格当成模板
“麦肯锡风”“极简风”是解释性描述，不会自动解析为本地模板工作区。
style = swiss-minimal
≠ Style workspace

          
wrong / 02
把原始 PPTX 当模板路径
想保留原设计并替换内容，走 Edit Native；想建立可复用系统，先 Create Template。
source.pptx ≠ templates/

          
right / 03
把结构和身份分开
最常见且稳妥的组合是 Brand + Layout：身份由 Brand 管，结构由 Layout 管。
Brand + Layout
identity + structure
