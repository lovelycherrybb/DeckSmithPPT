# ADR-001: PPT 生成引擎可插拔架构

- 状态: 已接受
- 日期: 2026-08-25
- 决策者: 龚成

## 背景

产品核心是"内容 → PPTX"。当前唯一引擎是 ppt-master（AI Agent 工作流），
但未来可能出现自研渲染器、第三方 API 等，且生成耗时差异巨大（分钟级）。

## 决策

1. 定义语言无关的引擎契约 `docs/contracts/engine.schema.json`（输入/输出/任务状态）。
2. `packages/engine/core/` 定义 PptEngine 协议：submit/status/result/resume（长任务语义）。
3. 各实现放 `packages/engine/impl/<name>/`，通过 registry 注册。
4. 调用方只依赖协议与注册表，禁止 import 具体实现。

## 后果

- 正面：新增引擎不改调用方；契约测试保证一致性。
- 代价：抽象层有额外开发成本；首个引擎上线前需定义好任务状态机。
