# ADR-005: 前端页面重新设计

- 状态: 已接受
- 日期: 2026-08-31
- 决策者: 龚成

## 背景

现有前端页面存在以下问题：
1. 界面设计缺乏视觉层次和品牌感，模板化设计看起来"很AI很不动脑子"
2. 没有首页该有的样子，缺少清晰的价值主张和行动号召
3. 任务执行页和历史页面放在一起很乱，信息架构混乱

设计文件位于 `designs/decksmith-redesign/`，包含完整的页面重新设计。

## 决策

### 1. 页面分离架构
- **首页** (`/`)：产品展示和价值主张，引导用户开始使用
- **工作台** (`/studio`)：专注于PPT生成流程，独立的任务执行页
- **历史记录** (`/studio/history`)：独立的历史页面，与任务执行分离

### 2. 设计系统
- **主色**：`#1f6feb` (专业蓝)
- **辅助色**：`#0f9d8f` (创意绿)
- **文本**：`#172033` (深灰)
- **背景**：`#f4f7fb` (浅灰)
- **字体**：Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif

### 3. 视觉风格
- 现代极简：干净、留白、层次清晰
- 专业感：建立品牌信任
- 创意感：避免模板化设计
- 一致性：统一的组件和交互模式

### 4. 组件设计
- 侧边栏导航：统一所有页面
- 卡片组件：圆角、阴影、边框
- 按钮组件：主次分明，状态清晰
- 表单组件：清晰的标签和提示

### 5. Logo设计
- DS字母组合 + 工匠元素
- 主色：`#1a1a2e` (深蓝)
- 强调色：`#4361ee` (亮蓝)
- 渐变效果：从深蓝到亮蓝

## 后果

### 正面
- 清晰的信息架构，用户知道在哪里做什么
- 专业的视觉设计，建立品牌信任
- 流畅的用户体验，减少认知负担
- 页面分离，职责单一，便于维护

### 代价
- 需要重新实现前端页面
- 需要设计和实现新的组件系统
- 需要更新现有的路由结构

2. 使用 Next.js App Router 路由结构
3. 实现响应式设计，支持移动端
4. 保持与后端的兼容性
