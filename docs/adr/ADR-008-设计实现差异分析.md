# ADR-008: 设计实现差异分析

- 状态: 已接受
- 日期: 2026-09-05
- 决策者: 龚成

## 背景

用户反馈前端工作台与设计不一致，并且有报错。经过详细对比分析，发现以下差异。

## 问题分析

### 1. 侧边栏导航差异

#### 设计页面 (studio.html)
```html
<nav class="sidebar-nav">
    <div class="nav-section">
        <div class="nav-section-title">创作</div>
        <a href="studio.html" class="nav-item active">新建 PPT</a>
        <a href="#" class="nav-item">模板库 <span class="nav-item-badge">12</span></a>
    </div>
    <div class="nav-section">
        <div class="nav-section-title">管理</div>
        <a href="#" class="nav-item">我的项目 <span class="nav-item-badge">5</span></a>
        <a href="history.html" class="nav-item">生成历史 <span class="nav-item-badge">23</span></a>
    </div>
    <div class="nav-section">
        <div class="nav-section-title">设置</div>
        <a href="#" class="nav-item">账户设置</a>
    </div>
</nav>
```

#### 实际实现 (studio/page.js)
```javascript
const menuItems = [
    { key: 'home', icon: <FileTextOutlined />, label: <Link href="/">首页</Link> },
    { key: 'studio', icon: <Sparkles />, label: <Link href="/studio">工作台</Link> },
    { key: 'history', icon: <ClockCircleOutlined />, label: <Link href="/history">生成历史</Link> },
];
```

#### 差异分析

| 功能 | 设计 | 实现 | 状态 |
|------|------|------|------|
| **新建 PPT** | ✅ | ✅ | ✅ 一致 |
| **模板库** | ✅ | ❌ | ❌ 缺失 |
| **我的项目** | ✅ | ❌ | ❌ 缺失 |
| **生成历史** | ✅ | ✅ | ✅ 一致 |
| **账户设置** | ✅ | ❌ | ❌ 缺失 |
| **导航分组** | ✅ 分组显示 | ❌ 扁平列表 | ❌ 不一致 |
| **徽章显示** | ✅ 显示数量 | ❌ 无徽章 | ❌ 不一致 |

### 2. 功能缺失分析

#### 2.1 模板库功能
**设计**：显示12个可用模板，支持模板选择
**实际**：完全没有实现
**影响**：用户无法使用预设模板，需要从零开始创建

#### 2.2 我的项目功能
**设计**：显示5个用户项目，支持项目管理
**实际**：完全没有实现
**影响**：用户无法管理已创建的项目

#### 2.3 账户设置功能
**设计**：用户账户设置页面
**实际**：完全没有实现
**影响**：用户无法管理账户信息

### 3. 侧边栏结构差异

#### 设计特点
- **分组导航**：创作、管理、设置三个分组
- **徽章显示**：显示模板数量、项目数量、历史记录数量
- **图标设计**：自定义SVG图标
- **视觉层次**：清晰的分组标题和间距

#### 实际实现
- **扁平导航**：三个独立菜单项
- **无徽章**：不显示数量信息
- **图标**：使用Ant Design图标
- **视觉**：简单的列表样式

### 4. 其他差异

#### 4.1 Logo区域
**设计**：
```html
<div class="sidebar-logo-icon">D</div>
<div class="sidebar-logo-text">
    <h1>DeckSmithPPT</h1>
    <p>AI PPT 生成助手</p>
</div>
```

**实际**：
```javascript
<Link href="/" style={{ fontSize: collapsed ? 16 : 18, fontWeight: 600, color: '#1a1a2e' }}>
    {collapsed ? 'DS' : 'DeckSmith'}
</Link>
```

**差异**：
- 设计有图标和副标题
- 实现只有文字Logo

#### 4.2 用户信息区域
**设计**：显示用户头像、姓名、邮箱
**实际**：完全没有实现

## 解决方案

### 方案1：完整实现设计（推荐）
按照设计页面完整实现所有功能：

1. **更新侧边栏导航**
   - 添加分组结构（创作、管理、设置）
   - 添加模板库菜单项
   - 添加我的项目菜单项
   - 添加账户设置菜单项
   - 添加徽章显示

2. **实现缺失功能**
   - 模板库页面和功能
   - 我的项目页面和功能
   - 账户设置页面

3. **优化视觉设计**
   - 实现Logo图标
   - 添加用户信息区域
   - 优化分组样式

### 方案2：渐进式实现
分阶段实现设计：

**阶段1**：修复侧边栏结构
- 添加分组导航
- 更新菜单项

**阶段2**：实现核心功能
- 模板库基础功能
- 项目管理基础功能

**阶段3**：完善功能
- 账户设置
- 用户信息显示

## 建议

### 立即修复
1. 更新侧边栏导航结构，添加分组
2. 添加缺失的菜单项（模板库、我的项目、账户设置）
3. 修复徽章显示

### 后续优化
1. 实现模板库功能
2. 实现项目管理功能
3. 实现账户设置功能
4. 优化视觉设计
