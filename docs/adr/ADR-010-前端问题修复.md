# ADR-010: 前端运行时错误修复

- 状态: 已接受
- 日期: 2026-09-07
- 决策者: 龚成

## 问题描述

用户遇到运行时错误：
```
Runtime TypeError: Cannot read properties of undefined (reading 'call')
```

## 问题分析

### 错误原因
1. **Next.js开发工具模块缺失**：`segment-explorer-node.js` 模块在React Client Manifest中找不到
2. **依赖损坏**：`node_modules` 可能损坏或不完整
3. **版本冲突**：Next.js版本可能存在兼容性问题

### 错误日志
```
⨯ Error: Could not find the module ".../next-devtools/userspace/app/segment-explorer-node.js#SegmentViewNode" in the React Client Manifest.
⨯ [TypeError: Cannot read properties of undefined (reading 'call')]
```

## 解决方案

### 步骤1：清理依赖
```bash
cd packages/frontend
rm -rf node_modules package-lock.json
```

### 步骤2：重新安装依赖
```bash
npm install
```

### 步骤3：验证构建
```bash
npm run build
```
