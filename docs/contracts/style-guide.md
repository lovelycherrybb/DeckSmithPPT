## 约束条件

### 安全约束

#### 两阶段调用
调用 Claude Code 时使用 `--dangerously-skip-permissions` 会跳过权限检查，可能导致安全风险。

**解决方案**：两阶段调用，分离检查和执行

**阶段一：安全检查（不跳过权限）**
```bash
claude -p "检查以下内容是否安全..."
# 不使用 --dangerously-skip-permissions
# 即使内容有注入，Claude 也会询问用户确认，不会自动执行
```

**阶段二：正式执行（跳过权限）**
```bash
claude -p --dangerously-skip-permissions "执行任务..."
# 检查通过后才执行
# 内容已确认安全，可以自动执行
```

### 数据约束

#### 草稿版本号
- 格式：年月日时分秒（如 20260907143025）
- 同一草稿同一秒内只能保存一次（防止版本冲突）

#### 草稿标识
- 每次文件生成草稿时创建新标识
- 编辑保存时标识不变

#### 文件名称
- 演示文件默认名称：项目名称_文件生成时间戳（UTC 年月日时分秒，如 `智慧园区能耗管理平台-建设方案_20260909061518.pptx`）
- 用**生成时刻**而非草稿版本号命名：同一草稿在不同时间节点重复出片时草稿版本号不变，会导致文件名撞车；生成时间戳保证每个文件名称唯一
- 草稿版本仍记在任务行（`job.draft_version`）用于追溯，不再进文件名

### 业务约束

#### 任务与输出的关系
- 一个草稿引擎任务生成一个草稿
- 一个输出引擎任务生成一个演示文件
- 一个项目可以有多个任务

#### 草稿与版本的关系
- 草稿可以有多个版本
- 历史版本不可变
- 可以还原到任意历史版本

#### 任务状态
- 状态只有4种：running、completed、failed、timeout
- 终态（completed/failed/timeout）不可逆

### 技术约束

#### 引擎可插拔
- 新引擎只需实现统一接口
- 引擎内部可调用 Agent 能力层
- Agent CLI 保持原生接口，不封装

#### 参数结构
- 草稿引擎参数固定：文件列表 + 提示词
- 输出引擎参数动态：每个引擎不同，前端根据参数模式渲染

#### 进度获取
- 状态明细通过轮询获取
- 需要读取 Agent 的输出流或日志文件

### 性能约束

#### 内容限制
- 草稿内容传递给 Claude 时，最多15000字符

#### 超时控制
- 任务需要设置最大执行时间
- 超时后任务状态变为 timeout

## 核心功能

- 横向翻页（键盘 ←→、滚轮、触屏、ESC 总览）
- 演讲者模式（右下角 P 键）：当前页/下一页 16:9 预览、讲稿备注、计时
- 观众屏同步（断线恢复）
- 章节幕封、数据大字报、图片网格等模板
- Motion One 入场动效
- 激光笔 / 圈选标注
- 单文件 HTML，可离线打开
