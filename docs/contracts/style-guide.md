# DeckSmithPPT 引擎参数指南（ppt-master）

> **引擎参数层文档**：描述当前引擎（ppt_master）在 `engine_params` 中支持的参数。
> 通用层（title/content/pages/engine）见 `engine.schema.json`；本文件是给人看的，schema 是给机器校验的。
> 换引擎时，本文件随新引擎重写。

## 叙事模式（Mode）

| 模式 ID | 中文名 | 说明 | 适合场景 |
|---------|--------|------|---------|
| auto | 自动 | 由引擎根据内容自动判断 | 通用 |
| pyramid | 金字塔 | 结论先行，用论据层层支撑 | 咨询、提案、汇报 |
| narrative | 叙事 | 故事驱动，起承转合 | 演讲、品牌、传记 |
| instructional | 教学 | 循序渐进，逐步引导 | 课程、教程、培训 |
| showcase | 展示 | 突出亮点，视觉主导 | 产品发布、路演、作品集 |
| briefing | 简报 | 客观信息，平铺事实 | 周报、日报、情报 |
