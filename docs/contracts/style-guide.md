## v6 引擎参数扩面（ADR-031）

`ppt_master_v6` 在原有参数之外多开的九项。控件类型全部由契约决定，前端不按参数名硬编码。
**九项一律可以不选**：不选表示用户没有表态，系统不下发该项，由生成能力自行判断（AGENTS 规则 10）。

| 参数键 | 中文名 | 控件 | 取值 / 说明 |
|---|---|---|---|
| `content_divergence` | 材料发散度 | 可点示例也可自己写 | 素材要贴多紧、可以多大程度重塑。三句示例见下 |
| `delivery_purpose` | 阅读模式 | 单选 | `text`=字多自读 / `balanced`=平衡 / `presentation`=字少靠讲；决定每页的文字量，仅 PPT 类画布有效 |
| `allow_web_research` | 是否允许上网补充素材 | 开关 | 关闭后仅使用已上传的素材，内容不足也不从外部获取、不补充素材中没有的事实 |
| `primary_language` | 主语言 | 单选 | `zh-CN` / `zh-TW` / `en-US` / `ja-JP` |
| `image_usage` | 配图来源 | 多选 | `ai`=AI生图 / `web`=网络搜图 / `provided`=只用我上传的 / `placeholder`=允许占位符 / `none`=不用图<br>其中「AI生图」一项**暂不支持**：当前没接入生图服务，界面上置灰选不动，直接调接口也会被拒（ADR-033） |
| `narration_audio` | 旁白音频 | 开关 | 开＝额外生成配音，耗时更长、更耗积分<br>**暂不支持**：当前环境缺少把配音合进文件的处理工具，选了会在最后导出那步失败，故界面置灰、后端拒收（ADR-033）；选「关闭」不受影响 |
| `audience` | 受众 | 自己写（高级区） | 这份演示讲给谁听 |
| `communication_intent` | 沟通意图 | 自己写（高级区） | 你要这场演示促成什么改变 |
| `core_message` | 核心信息 | 自己写（高级区） | 一句话让人记住的那句结论 |

### 材料发散度的三句示例

这三句只是"点击即填入"的便利，不限制只能选这三档；自行填写的内容原样下发：

1. 严格贴着素材来
2. 结构可以重排但内容不增不减
3. 在素材范围内自由重组并展开

未选择时按平衡处理：重排结构、提炼内容，并在素材范围内展开。

> 边界提醒：发散度再高也**不等于可以编造**。素材里没有的数字和事实不会被允许凭空出现，
> 那属于"是否允许上网补充素材"管的范围。

## 约束条件

### 安全约束

#### 两阶段调用
调用 Claude Code 时使用 `--dangerously-skip-permissions` 会跳过权限检查，可能导致安全风险。

**解决方案**：两阶段调用，分离检查和执行

**阶段一：安全检查（不跳过权限）**
```bash
claude -p "检查以下内容是否安全..."
# 不使用 --dangerously-skip-permissions
# 即使内容有注入，Claude 也会询问用户确认，不会自动执行
```

**阶段二：正式执行（跳过权限）**
```bash
claude -p --dangerously-skip-permissions "执行任务..."
# 检查通过后才执行
# 内容已确认安全，可以自动执行
```

### 数据约束

#### 草稿版本号
- 格式：年月日时分秒（如 20260907143025）
- 同一草稿同一秒内只能保存一次（防止版本冲突）

#### 草稿标识
- 每次文件生成草稿时创建新标识
- 编辑保存时标识不变

#### 文件名称
- 演示文件默认名称：项目名称_文件生成时间戳（UTC 年月日时分秒，如 `智慧园区能耗管理平台-建设方案_20260909061518.pptx`）
- 用**生成时刻**而非草稿版本号命名：同一草稿在不同时间节点重复出片时草稿版本号不变，会导致文件名撞车；生成时间戳保证每个文件名称唯一
- 草稿版本仍记在任务行（`job.draft_version`）用于追溯，不再进文件名

### 业务约束

#### 任务与输出的关系
- 一个草稿引擎任务生成一个草稿
- 一个输出引擎任务生成一个演示文件
- 一个项目可以有多个任务

#### 草稿与版本的关系
- 草稿可以有多个版本
- 历史版本不可变
- 可以还原到任意历史版本

#### 任务状态
- 状态共六种：排队中（queued）、生成中（running）、已完成（completed）、失败（failed）、超时（timeout）、已取消（cancelled）
- 终态（completed/failed/timeout/cancelled）不可逆；排队中与生成中属于未结束
- 界面用词一律取上表括号前的中文，不得直接显示英文原值（AGENTS 规则 11）

### 技术约束

#### 引擎可插拔
- 新引擎只需实现统一接口
- 引擎内部可调用 Agent 能力层
- Agent CLI 保持原生接口，不封装

#### 参数结构
- 草稿引擎参数固定：文件列表 + 提示词
- 输出引擎参数动态：每个引擎不同，前端根据参数模式渲染

#### 进度获取
- 状态明细通过轮询获取
- 需要读取 Agent 的输出流或日志文件

### 性能约束

#### 内容限制
- 草稿内容传递给 Claude 时，最多15000字符

#### 超时控制
- 任务需要设置最大执行时间
- 超时后任务状态变为 timeout

## 核心功能

- 横向翻页（键盘 ←→、滚轮、触屏、ESC 总览）
- 演讲者模式（右下角 P 键）：当前页/下一页 16:9 预览、讲稿备注、计时
- 观众屏同步（断线恢复）
- 章节幕封、数据大字报、图片网格等模板
- Motion One 入场动效
- 激光笔 / 圈选标注
- 单文件 HTML，可离线打开
