# VC Design (Vibecoding Design) 文档

## 目录说明

`docs/vc_design/` 目录包含项目的整体设计文档，采用 vibecoding 的设计理念。

## 文档结构

该目录包含以下子目录，代表系统设计的不同层面：

- **objects/**: 对象定义和数据模型
- **states/**: 状态机和状态转换
- **interfaces/**: 接口定义和API规范
- **flows/**: 工作流程和业务流程
- **constraints/**: 约束条件和业务规则

## 设计理念

VC Design 是整个项目的最基础设计层，负责整体对话级设计。这一层的设计可以很口语化、也可以很专业化，设计取决于操控者的实际数字化能力，但不影响代码产出。

## 与 ADR 的区别

- **ADR（架构决策记录）**：记录单个技术/架构决策的历史
- **VC Design**：描述系统的当前设计和架构

## 文档维护

1. 每个子目录应包含相关的 `.md` 文件
2. 文件应遵循统一的命名规范
3. 文档应保持与代码实现的一致性
4. 重大设计变更应更新相应的文档
