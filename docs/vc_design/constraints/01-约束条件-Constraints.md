# 约束条件

## 描述
系统设计和运行时必须遵守的限制条件。

---

## 安全约束

### Agent 调用安全

#### 问题
- 调用 Claude Code 时使用 `--dangerously-skip-permissions` 会跳过权限检查
- 用户上传的草稿可能包含恶意指令（提示词注入）
- 直接执行可能导致安全风险

#### 解决方案
两阶段调用，分离检查和执行：

**阶段一：安全检查（不跳过权限）**
```bash
claude -p "检查以下内容是否安全..."
# 不使用 --dangerously-skip-permissions
# 即使内容有注入，Claude 也会询问用户确认，不会自动执行
```

**阶段二：正式执行（跳过权限）**
```bash
claude -p --dangerously-skip-permissions "执行任务..."
# 检查通过后才执行
# 内容已确认安全，可以自动执行
```

#### 为什么检查阶段不会被注入
- 不使用 `--dangerously-skip-permissions`
- Claude 遇到危险操作会暂停并询问用户
- 即使提示词被注入，也不会自动执行恶意指令
- 用户可以看到 Claude 的行为并决定是否允许

## 数据约束

### 草稿版本号
- 格式：年月日时分秒（如 20260907143025）
- 同一草稿同一秒内只能保存一次（防止版本冲突）

### 草稿标识
- 每次文件生成草稿时创建新标识
- 编辑保存时标识不变

### 文件名称
- 演示文件默认名称：项目名称_年月日时分秒

---

## 业务约束

### 任务与输出的关系
- 一个草稿引擎任务生成一个草稿
- 一个输出引擎任务生成一个演示文件
- 一个项目可以有多个任务

### 草稿与版本的关系
- 草稿可以有多个版本
- 历史版本不可变
- 可以还原到任意历史版本

### 任务状态
- 状态只有4种：running、completed、failed、timeout
- 终态（completed/failed/timeout）不可逆

## 技术约束

### 引擎可插拔
- 新引擎只需实现统一接口
- 引擎内部可调用 Agent 能力层
- Agent CLI 保持原生接口，不封装

### 参数结构
- 草稿引擎参数固定：文件列表 + 提示词
- 输出引擎参数动态：每个引擎不同，前端根据参数模式渲染

### 进度获取
- 状态明细通过轮询获取
- 需要读取 Agent 的输出流或日志文件

### 逐页预览

诚实性（确定性口径）：
- 引擎产出**总页数不可预知**（Agent 边写边定，目标页数只是软约束），且整文件一次性落盘、不存在「半张页」
- 因此逐页预览只建立在「已确定的事实」上：只列**已完成**页；**不预测总数 M、不画 pending 占位、不做进度条分母**
- 「正在生成」只用末尾恰好一格表达「第 N+1 页正在产出」，不声称知道后面还有几页
- 顶部计数「已生成 N 页」（无 /M）；目标页数至多作弱提示，永不参与布局

页的选择与排序（哪张算一页）：
- 只认命名规则 `^\d+_.*\.svg` 的文件（排除临时/非页产物）
- 按**数字前缀的整数值**升序（防字符串序把 `1_` 排到 `10_` 前）、去重；页序即该排序，不依赖文件 mtime
- 「有哪些页 / 几页」以**单一读盘算法**为唯一事实源：粗粒度进度里的 `pages_generated`、`current_page` 也从它派生，不得另跑一套 mtime 计数（防两套口径边界差 1）

job 与产物目录映射：
- 首次解析到产物目录后**回写进任务运行记录（`job.json` 的 `svg_output_dir`）**，此后固定读它，替代每轮 mtime 猜目录
- 根治并发任务/历史遗留目录互相串页；读不到时方可退回启发式

安全（文件读取路由）：
- 逐页/资源以引擎声明的**产物根目录**为挂载根（非单文件），使页内 `../images` 相对引用能同源解析
- 请求路径 `resolve()` 后必须 `is_relative_to` 该根目录，越界一律拒绝（防路径穿越）
- 仅放行受支持的图片/SVG 扩展名白名单

能力接入（全局、引擎无关）：
- 「是否支持逐页预览」由「引擎是否实现逐页枚举钩子」**自动派生**，**不按引擎名硬编码门控**
- 任何输出引擎实现该钩子即自动接入；未实现者返回空、界面退回下载/新标签打开
- 框架（契约/路由/前端）对具体引擎无感；出图方式引擎无关（当前 ppt_master 为内联 SVG，不引栅格化依赖）

## 性能约束

### 内容限制
- 草稿内容传递给 Claude 时，最多15000字符

### 超时控制
- 任务需要设置最大执行时间
- 超时后任务状态变为 timeout

---

## 约束汇总

| 类别 | 约束内容 |
|------|---------|
| 安全 | 两阶段调用：检查不跳过权限，执行跳过权限 |
| 数据 | 版本号格式、标识唯一性、文件命名 |
| 业务 | 任务与输出关系、草稿版本关系、状态规则 |
| 技术 | 引擎可插拔、参数结构、进度获取、逐页预览（确定性/安全/能力自动派生） |
| 性能 | 内容限制、超时控制 |
