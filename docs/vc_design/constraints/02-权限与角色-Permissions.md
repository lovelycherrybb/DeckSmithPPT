# 权限与角色

## 描述

系统角色、权限判定与数据可见性的唯一事实源。各对象文档（用户、项目、用户偏好）只引用本文件，不各自重述矩阵，避免多处口径漂移。

---

## 角色定义

单一枚举，互斥，三值：

- **管理员（manager）**：内置唯一账号 `manager`，默认密码 `234567`；不可被创建、编辑、删除或禁用；拥有高级用户全部功能 + 用户管理。
- **高级用户（vip）**：全部生成功能（含引擎参数可调），无用户管理。
- **普通用户（normal）**：能选引擎并生成，但引擎参数只读禁用。

叠加一个正交状态：**启用 / 禁用**。禁用＝保留数据与项目，仅禁止登录；由管理员切换，管理员自身不可被禁用。

配置界面上的「是否 Vip」开关，本质是在 `normal ↔ vip` 间切换角色；管理员不参与该开关。

## 权限矩阵

| 能力 | 未登录（访客） | 普通用户 | 高级用户 | 管理员 |
|------|:---:|:---:|:---:|:---:|
| 进入工作台、选引擎生成 | ✓（限工作台） | ✓ | ✓ | ✓ |
| 编辑引擎参数 | ✗（只读禁用） | ✗（只读禁用，提示需高级） | ✓ | ✓ |
| 查看项目范围 | 仅本次访客期项目 | 仅自己 | 仅自己 | 全部（含未认领访客项目，列表多「归属用户」列） |
| 历史项目菜单 | ✗（跳登录） | ✓ | ✓ | ✓ |
| 设置（本人偏好） | ✗（跳登录） | ✓ | ✓ | ✓ |
| 用户管理菜单 | ✗（跳登录） | ✗ | ✗ | ✓ |
| 修改自己的密码 | —（无账号） | ✓ | ✓ | ✓ |
| 新增/改信息/重置密码/启用禁用 他人 | ✗ | ✗ | ✗ | ✓ |
| 删除 / 代为认领 未认领访客项目 | ✗ | ✗ | ✗ | ✓ |

> 访客能力对齐普通用户（可用工作台、引擎参数禁用），只是无账号、无偏好、无历史。

## 登录态与菜单访问

- 顶栏菜单：**工作台**对所有人开放（含未登录试用）；**历史项目 / 设置 / 用户管理**需登录，未登录点击一律跳转登录页。
- 用户管理菜单**额外**要求角色为管理员；非管理员即便已登录也不显示、直连接口亦拒绝。
- 登录后右上角出现用户头像（默认用户名首字母），下拉含「修改密码」「退出登录」。

---

## 引擎参数门控

- 普通用户与访客：生成弹窗/创建向导里的引擎参数区**照常展示但整体禁用**，附提示「升级为高级用户可调整参数」；提交时按引擎默认参数走，不接受其传入的参数改动。
- **禁用只是体验层，后端必须独立按角色复核**：普通用户即便直接打接口提交自定义参数，后端也应忽略或拒绝——权限不能只靠前端 disabled 兜。

---

## 项目可见性与归属

- 项目必有一个归属主体（真实用户，或未认领的访客会话）；列表/详情/下载/预览等一切读取都按归属过滤。
- 普通/高级用户只能访问归属自己的项目；访问他人项目一律拒绝（不区分 403/404 细节时优先按不泄露存在性的方式处理）。
- 管理员跳过归属过滤看全部，**含尚未被认领的访客试用项目**（这类无真实归属人，管理员是唯一能全局看到它们的人），且界面多显示「归属用户」列，未认领者显示「未认领（访客）」；用户界面不显示该列。管理员对未认领访客项目可查看、删除，并可代为认领（重新归属到指定真实用户）。
- 任务、草稿、演示文件不单独存归属，一律经所属项目推导（项目级归属为唯一隔离点）。

---

## 用户管理边界（仅管理员）

- 可新增用户：用户名必填且唯一、昵称、手机号选填、是否 Vip（决定 normal/vip）；初始密码统一 `234567`。
- 可改用户信息，**用户名除外**（用户名是登录锚点，创建后不可改）。
- 可重置任意（非管理员）用户密码为 `234567`。
- 可启用 / 禁用账号；禁用只挡登录、不动数据。
- 管理员账号 `manager` 不出现在可被编辑/禁用/删除的范围内。

---

## 访客认领

- 未登录时服务端建访客会话、cookie 承载访客令牌；试用产生的项目挂该访客。
- 登录成功后，把该访客令牌下的项目**重新归属**到登录的真实用户，试用成果不丢。
- 访客不加载用户偏好（无账号），使用系统默认。

---

## 可扩展口子

本期 normal 与 vip **仅差「引擎参数可编辑」一项**，其余全同。未来若新增差异（页数上限、可用引擎种类、生成配额等），在本矩阵加行、并在后端门控点补一处复核即可，不改角色枚举本身。

---

## 安全底线

- 一切权限判定以**后端**为准；前端禁用/隐藏只是体验，不作为安全边界。
- 密码仅存哈希（bcrypt/argon2），任何接口不回显密码。
- 会话走服务端 Session + httpOnly Cookie；登出/禁用即时失效，不依赖前端持有的任何凭据。

---

## 约束汇总

| 类别 | 约束内容 |
|------|---------|
| 角色 | 三值枚举 manager/vip/normal + 正交启用/禁用状态；内置 manager 不可被管理 |
| 门控 | 引擎参数仅 vip/manager 可编辑；后端独立复核，前端禁用非安全边界 |
| 可见性 | 项目按归属隔离；管理员看全部且多归属列；任务/草稿/演示文件经项目推导 |
| 菜单 | 工作台开放试用；历史/设置/用户管理需登录；用户管理额外需管理员 |
| 用户管理 | 用户名不可改；重置密码统一 234567；禁用不删数据 |
| 访客 | 访客令牌试用，登录后并入真实用户 |
| 安全 | 后端强制鉴权；密码哈希；Session+httpOnly Cookie |
