# 核心流程

## 用户操作流程

---

## 浏览项目列表并打开项目

**场景**：用户想看看自己做过哪些项目，然后打开某个项目

**怎么做**：
1. 进入项目列表页，看到所有项目
2. 每个项目显示名称、创建时间、最近更新等信息
3. 点击某个项目，进入项目详情页

---

## 从零开始做一个PPT

**场景**：用户第一次用，想做一个新的演示文件

**怎么做**：
1. 上传自己的文件（Word、PDF、网页链接等），可以一次传多个
2. 选一个草稿引擎，让系统帮忙转成 Markdown 草稿
3. 系统自动创建一个项目
4. 用户可以看看草稿，觉得不满意就改改
5. 选一个输出引擎（比如 pptmaster），调调参数（风格、尺寸等）
6. 点生成，得到 PPT 或 HTML 文件

---

## 看看以前做过哪些草稿

**场景**：用户想看看这个项目之前生成过哪些草稿

**怎么做**：
1. 打开项目
2. 看草稿列表，每个草稿都可以展开看历史版本

---

## 看看以前生成过哪些PPT

**场景**：用户想看看这个项目之前生成过哪些演示文件

**怎么做**：
1. 打开项目
2. 看演示文件列表，可以下载或预览

---

## 改改草稿重新生成

**场景**：用户觉得之前的草稿要改一下，然后重新生成PPT

**怎么做**：
1. 打开项目，找到要改的草稿
2. 编辑内容，保存成新版本
3. 选输出引擎，调参数
4. 生成新的演示文件

---

## 上传更多文件生成新草稿

**场景**：用户想在项目里再传一批文件，生成一个新的草稿

**怎么做**：
1. 打开项目
2. 上传新文件（可以一次传多个），选草稿引擎
3. 生成一个新草稿
4. 想继续传就重复上面的步骤

---

## 回到草稿的某个历史版本

**场景**：用户改来改去，想回到之前某个版本

**怎么做**：
1. 打开项目，找到草稿
2. 看版本历史列表
3. 选一个历史版本，恢复成当前版本

---

## 用不同风格重新生成

**场景**：用户想用同一个草稿，但换个风格或引擎重新生成

**怎么做**：
1. 打开项目，选一个草稿版本
2. 选不同的输出引擎，或者改改参数
3. 生成新的演示文件

---

## 改已生成的 PPT（逐页修改，得到新版本）

**场景**：pptmaster 生成的 PPT 出来后，某页文字/图/版式想微调，或想在某个版本基础上继续改

**怎么做**：
1. 打开项目，进演示文件库，找到要改的文件（仅 pptmaster 系产物有「修改」按钮），点「修改」
2. 右侧滑出抽屉式修改工作台，逐页拖拽/改字/改色，或直接打字让 AI 帮你改
3. 点「保存」，系统后台重新导出，得到一个「子演示文件」（不覆盖原文件）
4. 预览顶部可在"原文件 / 各子文件"间切换（缩进树）；下载时按缩进树选要哪个版本
5. 想继续改，可从任一子文件再点「修改」→ 分叉出新的子文件

> 详细机制见 `flows/04-pptmaster修改流程`、对象见 `objects/08-子演示文件`。

---

## 看看任务跑到哪了

**场景**：用户点了生成，想看看进度

**怎么做**：
1. 打开项目，看任务列表
2. 找到正在跑的任务，点进去看状态明细
3. 能看到引擎当前在干嘛（比如"正在生成第3页..."）

---

## 任务失败了想重试

**场景**：任务跑失败了，用户想再试一次

**怎么做**：
1. 打开项目，看任务列表
2. 找到失败的任务，点重试
3. 任务重新执行

---

## 一句话总结

| 场景 | 一句话 |
|------|--------|
| 打开项目 | 项目列表 → 选一个项目 → 进入详情 |
| 新建 | 上传文件 → 转草稿 → 生成PPT |
| 查看草稿 | 打开项目 → 看草稿列表 |
| 查看生成 | 打开项目 → 看演示文件列表 |
| 重新编辑 | 改草稿 → 保存新版本 → 重新生成 |
| 再传文件 | 传新文件 → 生成新草稿 |
| 还原版本 | 选草稿 → 选历史版本 → 恢复 |
| 重新生成 | 选草稿 → 换引擎/参数 → 生成 |
| 改 PPT | 演示文件库 → 修改 → 逐页改 → 保存出新版本（子文件，可分叉） |
| 看进度 | 打开任务 → 看状态明细 |
| 重试 | 找失败任务 → 点重试 |
