# 系统接口

## 描述
系统对外提供的能力，供前端调用。

## 鉴权总则（横切所有接口）

- 除「登录、当前用户查询、注册外的公开入口」外，所有接口都要过身份判定；未登录访问受限接口 → 跳登录（前端）/ 401（后端）。
- **权限一律后端强制**：前端隐藏/禁用只是体验，不作为安全边界（见 `constraints/02-权限与角色`）。
- **项目及其下游（任务/草稿/演示文件）按归属过滤**：普通/高级用户只能读写归属自己的项目及其资源；管理员放开全部。越权访问按不泄露存在性的方式拒绝。
- 会话走服务端 Session + httpOnly Cookie；本文件接口不显式写鉴权参数，默认都带当前身份上下文。

## 身份与鉴权

### 登录
- 输入：用户名、密码
- 输出：当前用户信息（用户标识、用户名、昵称、角色、状态）
- 说明：校验通过建会话并下发 Cookie；账号被禁用 → 拒绝并提示；成功后若当前浏览器有访客令牌，触发认领（见下）

### 登出
- 输入：无
- 输出：成功信号
- 说明：服务端销毁会话、清 Cookie

### 获取当前用户
- 输入：无
- 输出：当前用户信息；未登录时返回访客身份标识（供试用与认领用）
- 说明：前端据此渲染头像、决定菜单可见与角色门控

### 修改自己的密码
- 输入：旧密码、新密码
- 输出：成功信号
- 说明：仅改本人；不影响当前会话

### 访客项目认领
- 输入：无（凭当前访客 Cookie + 已登录身份）
- 输出：并入的项目数量
- 说明：登录成功后自动触发，把访客令牌下产生的项目重新归属到登录用户；无访客项目则为空操作

## 项目相关

### 获取项目列表
- 输入：分页参数
- 输出：项目列表
- 说明：按当前身份归属过滤——普通/高级用户只返回自己的项目；管理员返回全部，且每条带「归属用户」字段（供管理员视图多显示一列）

### 获取项目详情
- 输入：项目标识
- 输出：项目信息 + 关联的任务、草稿、演示文件
- 说明：非归属人（非管理员）访问 → 拒绝（不泄露存在性）

### 删除项目（仅管理员）
- 输入：项目标识
- 输出：成功信号
- 说明：系统此前无项目删除能力，本条为新增；本期只放开管理员删除**未认领的访客项目**，是否扩展到删除任意项目待定

### 代为认领项目（仅管理员）
- 输入：项目标识、目标用户标识
- 输出：更新后的项目（归属变更为目标用户）
- 说明：把一个未认领的访客项目重新归属到指定真实用户，用于试用者换设备登录、无法自助认领时的人工归位

## 任务相关

### 创建草稿引擎任务
- 输入：项目标识（可选）、引擎选择、文件列表、提示词（可选）
- 输出：新创建的任务

### 创建输出引擎任务
- 输入：项目标识、引擎选择、草稿标识、草稿版本、引擎参数
- 输出：新创建的任务

### 获取项目下的任务列表
- 输入：项目标识、状态筛选（可选）、分页参数
- 输出：任务列表

### 获取任务详情
- 输入：任务标识
- 输出：任务信息 + 当前状态明细

### 重试失败的任务
- 输入：任务标识
- 输出：新创建的任务
- 说明：只有没成功的结束态（失败、超时、已取消）能重试；原任务状态不变，另开一个新任务

### 修改演示文件（发起一次修改）
- 输入：要改的那个版本（原始演示文件，或某个子文件）、改好的逐页内容或用户的一句修改指令、用哪个 AI
- 输出：新创建的一次修改任务（和其它任务一样排队、能看进度、能重试）
- 说明：只有能逐页编辑的产物才有这个操作（看引擎自报的本事，不按引擎名字硬判，见 constraints 逐页预览）；改的起点可以是原始文件或任一子文件 → 往下分叉；用户点"保存"就发起这次修改、并在背后重新出成品，出成功才留下一个子演示文件（见 `flows/04-pptmaster修改流程`）

### 看某任务生成了哪些页（逐页预览）
- 输入：任务标识
- 输出：这个任务目前**已完成**的页，一页一页列出来；再带上整体状态、现在进行到哪一步（在生成还是在导出）、一共生成了几页。这是一份临时读出来的视图，不单独存库。
- 说明：
  - 只列已经完成的页，不猜总共几页、不放"还没生成"的占位格（诚实性见 constraints 逐页预览）
  - "正在生成第 N+1 页""正在导出成品"这些进度格，由前端按当前状态自己补上去显示，不在这份数据里
  - 不支持逐页产物的引擎（单文件 HTML、草稿那类）就是空清单，前端退回原来的下载/新标签打开
  - 子演示文件也用这个能力：拿"产生它的那次修改任务"来查，就能一页页看它自己那份内容，不额外开新接口

### 取某一页或页里引用的资源
- 输入：任务标识、页或资源在这个任务产物里的位置
- 输出：该文件的内容（页面、图片各按自己的类型返回）
- 说明：
  - 以引擎声明的那个产物目录为根，页面里引用到的图片等才能一起正确显示
  - 只放行受支持的文件类型；请求的位置必须落在根目录里，越界的直接拒（防路径穿越，见 constraints 逐页预览）

## Agent 文本能力

### Agent 文本处理（同步接口）
- 输入：任务类型（kind）、该类型的输入参数
- 输出：AI 返回的文本
- 说明：
  - 本质是同一个能力：服务端组装上下文 → 提示词模板 → Agent → 纯文本返回
  - kind 是后端注册的白名单（非任意提示词透传），新增能力 = 注册新 kind + 提示词模板
  - 调用方式与安全约束沿用两阶段设计：纯文本任务不跳过权限；输入内容先过安全检查门禁

### Agent 文本处理（异步接口）
- 输入：任务类型（kind）、该类型的输入参数
- 输出：会话ID、agent类型（立即返回）
- 说明：
  - 与同步接口相同的输入参数，但立即返回会话ID和 agent 类型，后台异步执行
  - 适用于长时间运行的任务，避免前端超时
  - 安全约束与同步接口一致
  - 返回的 agent 类型用于确定使用哪个原生接口查询会话状态

### 查询 Agent 会话状态（代理接口）
- 输入：会话ID
- 输出：会话状态、最新输出片段、完成时间等
- 说明：
  - 直接代理到对应 Agent 的原生查询接口，不进行额外封装
  - 会话状态：running（运行中）、completed（已完成）、failed（失败）
  - 最新输出片段：agent 当前正在处理的内容（可选）
  - 完成时间：仅 completed 或 failed 状态时有值

### 获取 Agent 会话流式输出（代理接口）
- 输入：会话ID
- 输出：SSE（Server-Sent Events）流式输出
- 说明：
  - 直接代理到对应 Agent 的原生流式输出接口，不进行额外封装
  - 实时获取 agent 的输出，支持流式显示
  - 适用于需要实时反馈的场景（如修改草稿、拟标题等）
  - 流式输出格式：每行一个 JSON 对象，包含 type 和 data 字段
  - type 类型：
    - `text`：文本输出片段
    - `status`：状态更新（如"正在分析内容..."）
    - `error`：错误信息
    - `done`：完成信号

### 预置任务类型（kind）

#### modify_draft：修改草稿
- 输入：草稿标识、当前版本、用户的修改提示词
- 服务端取该版本内容作为上下文
- 输出：修改后的 Markdown（供前端渲染，用户确认后再保存）
- 说明：Agent 理解用户意图，返回修改后的内容

#### suggest_title：拟演示文件标题
- 输入：文件列表（已上传文件的文件名和路径）
- 规则：单个文件直接用文件名（不调 Agent）；多个文件由 Agent 通读内容拟概括性标题
- 输出：标题文本

## 演示文件相关

### 获取项目下的演示文件列表
- 输入：项目标识
- 输出：演示文件列表

### 获取/下载演示文件
- 输入：演示文件标识
- 输出：文件内容

### 看一个演示文件的所有版本（版本树）
- 输入：演示文件标识
- 输出：这个原始演示文件，加上它派生出的所有子文件，先平着给一串；每一条能看出它是谁、改自哪个版本、由哪次修改任务产生、文件名、保存时间
- 说明：子演示文件是通用概念，但当前只有能逐页改的产物才会有子文件；前端按"改自哪个版本"的指向把它拼成缩进树、分叉并列着看（口径见 `objects/08-子演示文件`）；展开、选中只是临时界面状态，不入库

### 下载指定版本
- 输入：版本标识（原始演示文件 或 某个子文件）
- 输出：那一版对应的成品文件
- 说明：下载时弹出一棵版本树，选哪版下哪版

## 用户管理（仅管理员）

> 本组接口一律要求当前身份为管理员；非管理员调用直接拒绝。管理员账号 `manager` 不在可编辑/禁用/删除范围内。

### 获取用户列表
- 输入：分页/筛选（可选）
- 输出：用户列表（用户名、昵称、手机号、角色、状态、创建时间；不含密码）

### 新增用户
- 输入：用户名（必填、唯一）、昵称、手机号（选填）、是否 Vip
- 输出：新用户信息
- 说明：角色按是否 Vip 落 normal/vip；初始密码固定 `234567`

### 修改用户信息
- 输入：用户标识、昵称、手机号、是否 Vip
- 输出：更新后的用户信息
- 说明：**用户名不可改**，不在入参内

### 重置用户密码
- 输入：用户标识
- 输出：成功信号
- 说明：重置为 `234567`，不返回明文

### 启用 / 禁用用户
- 输入：用户标识、目标状态
- 输出：更新后的用户信息
- 说明：禁用只挡登录、保留数据与项目

## 安全检查

### 草稿安全检查
- 输入：草稿内容（Markdown）
- 输出：检查结果（通过/不通过）+ 原因
- 说明：
  - 在提交给 Agent 之前进行安全检查
  - 检查内容是否包含恶意指令、提示词注入等
  - 检查通过才允许调用 Agent
  - 不通过则返回原因，提示用户修改

### 检查规则
- 检查范围：正文散文。检测前先剥离 fenced 代码块（``` 围栏，含被截断的未闭合围栏）与行内代码（`…`）
  ——技术文档（设计稿、README 等）的架构图/代码片段是正当素材，注入意图只会出现在散文里
- 是否包含系统指令注入（如忽略之前的指令、执行命令等）
- 是否包含敏感内容
- 是否试图访问未授权资源
- 是否包含可疑的代码执行指令（仅对散文生效，代码块内出现 `subprocess.` 等字样不算；
  祈使句式须带指示宾语（执行以下/如下命令）或礼貌指令（请执行…）才拦，描述句（"按步骤执行脚本"）不拦）
