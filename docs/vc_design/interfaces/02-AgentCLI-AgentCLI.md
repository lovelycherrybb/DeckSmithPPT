# Agent CLI

## 描述
不同 AI Agent 的命令行工具。系统直接调用原生接口，不进行封装。

---

## Claude CLI

### 说明
Anthropic 的 AI 助手命令行工具

### 调用方式
- 发送任务：`claude -p "prompt"`
- 继续对话：通过会话ID恢复之前的对话

### 核心能力
- 发送对话：给 Claude 发送指令
- 获取结果：读取 Claude 的输出
- 继续对话：通过会话ID继续之前的对话
- 查询执行状态：
  - 读取子进程的 stdout 输出流
  - 读取日志文件
  - 通过会话ID查询对话历史

### 任务关联
```
创建任务 → 启动 Claude 子进程 → 记录会话ID
    ↓
查询任务 → 通过会话ID/进程ID → 获取执行状态
```
