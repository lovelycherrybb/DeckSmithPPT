# pptmaster 草稿引擎

## 描述
基于现有 Python 实现的草稿生成引擎，直接处理用户上传的文件并提取内容生成 Markdown 草稿。

## 所属类型
草稿生成引擎（DraftEngine）

## 特点
- 直接调用现有 pptmaster 提取的代码
- 处理速度快，不依赖外部 AI 服务
- 适合结构化文件的提取

## 参数结构（固定）
- **files**：文件列表，支持多种类型多份文件上传
- **prompt**：草稿生成提示词（选填），指导生成风格或要求

## 输入输出
- 输入：用户上传的文件（docx/pdf 等）
- 输出：新草稿（新 draft_id，初始版本）
