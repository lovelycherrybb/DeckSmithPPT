# Claude 草稿引擎

## 描述
基于 Claude Code 的草稿生成引擎，通过 AI 理解用户上传的材料并生成结构化的 Markdown 草稿。

## 所属类型
草稿生成引擎（DraftEngine）

## 特点
- 调用 Claude Code 能力层进行内容理解和生成
- 能处理非结构化、复杂的内容
- 生成的草稿更智能、结构更清晰

## 参数结构（固定）
- **files**：文件列表，支持多种类型多份文件上传
- **prompt**：草稿生成提示词（选填），指导 AI 理解和生成方向

## 输入输出
- 输入：用户上传的文件（任意格式）
- 输出：新草稿（新 draft_id，初始版本）
