# PPTX 输出引擎（ppt-master）

## 描述

把 Markdown 草稿做成**原生、可编辑的 PPTX 演示**的输出引擎。

## 属于哪类、叫什么

- 类型：输出引擎
- 引擎名：ppt_master，背后是上游 ppt-master 技能（本地只读副本）

## 核心特点

- **原生可编辑**：生成的是真正的 PPTX 对象，能在 PowerPoint 里直接改，不是把图片贴进去
- **多风格**：十几种视觉风格可选（极简、编辑风、粗犷等）
- **多叙事模式**：自动判断、汇报、讲故事等骨架
- **靠 AI 排版**：交给 AI 理解内容后自己排，不需要外部图片素材，图形、图标、文字都是原生生成

## 两种生成模式

- **完整模式**：先研究主题、再定内容策略、然后出配图、最后渲染导出。适合需要精细策划的正式演示。
- **快速模式**：备好素材后直接决策、逐页写、再检查导出，跳过中间的策略确认。适合快速出片、内部分享。

## 进什么、出什么

- 进：一份 Markdown 草稿（来自草稿引擎）
- 出：一个原生可编辑的 PPTX 演示文件

## 有哪些参数

- 基本项：草稿内容（有长度上限）、标题、目标页数、内容风格
- 风格与呈现：视觉风格、叙事模式、画布尺寸（默认 16:9 宽屏，另有 4:3、超宽等）、要不要带演讲备注、动画策略

> 确切的参数名、取值、默认值和长度上限以契约 `docs/contracts/engine.schema.json` 为准，这里只讲人话。

## 适合 / 不适合

**合适**：正式商业演示、要能拿去继续编辑的原生 PPTX、需要精细排版和风格控制、产品发布、年度汇报。

**不合适**：要网页交互/动画的（改用网页引擎）、只想快速迭代原型（网页引擎更快）、纯数据可视化（该上专门的 BI 工具）。

## 大致怎么跑

和网页引擎一条路子，靠 AI 命令行工具（Claude Code）跑：先把草稿和拼好的提示词落到这个任务自己的目录，拉起 AI 子进程跑，一边监控进度一边等产物，成功后成品 PPTX 落在任务目录里。要逐页看进度的能力，见 `flows/02-pptmaster生成流程`。

## 跑起来需要什么

- 机器上能用 AI 命令行工具（Claude Code），能连上模型
- 装了 Node（处理逐页设计稿要用）
- 装了 Python（技能里的脚本工具要用）
