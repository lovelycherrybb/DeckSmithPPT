# HTML 输出引擎（guizang-ppt-skill）

## 描述

基于 guizang-ppt-skill 的 HTML 演示文稿生成引擎，将 Markdown 草稿转化为单文件横向翻页网页 PPT。

## 所属类型

输出引擎（OutputEngine）

## 引擎标识

- **引擎名**：`guizang_ppt`
- **引擎类型**：`output`
- **Skill 来源**：[guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill)（歸藏创建）

## 两种视觉风格

### 风格 A · 电子杂志 × 电子墨水（默认）

- WebGL 流体 / 等高线 / 色散背景
- 衬线标题（Noto Serif SC + Playfair Display）+ 非衬线正文
- 适合：人文分享、行业观察、商业发布、需要"杂志感"的演讲

### 风格 B · 瑞士国际主义（Swiss Style）

- WebGL 极细网格 + 点阵背景
- 全程无衬线（Inter + Helvetica + Noto Sans SC）+ 极致字号对比
- 高反差功能色：克莱因蓝 / 柠檬黄 / 柠檬绿 / 安全橙
- 适合：科技产品、数据汇报、设计/工程领域分享

## 核心功能

- 横向翻页（键盘 ←→、滚轮、触屏、ESC 总览）
- 演讲者模式（右下角 P 键）：当前页/下一页 16:9 预览、讲稿备注、计时
- 观众屏同步（断线恢复）
- 章节幕封、数据大字报、图片网格等模板
- Motion One 入场动效
- 激光笔 / 圈选标注
- 单文件 HTML，可离线打开

## 输入输出

- **输入**：Markdown 草稿内容（来自草稿引擎）
- **输出**：单文件 HTML 演示文稿（含 CSS/JS，可直接浏览器打开）

## 参数结构

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `style` | string | 否 | 视觉风格：`magazine`（默认）或 `swiss` |
| `theme` | string | 否 | 主题色（杂志风 5 套 / 瑞士风 4 套） |
| `title` | string | 否 | PPT 标题 |
| `pages` | integer | 否 | 目标页数（默认根据内容自动） |

## 适用场景

**合适**：
- 线下分享 / 行业内部讲话 / 私享会
- AI 产品发布 / demo day
- 需要强烈个人风格的演讲
- 一次做完、不用翻页工具的网页版 slides

**不合适**：
- 大段表格数据、图表叠加
- 培训课件（信息密度不够）
- 需要多人协作编辑（静态 HTML）

## 执行方式

与 ppt-master 引擎一致，通过 Claude Code 子进程执行，区别在于产物格式（HTML vs PPTX）。

### 构建 Prompt

```
请使用 guizang-ppt-skill 技能生成 HTML 演示文稿：
- 主题：{title}
- 视觉风格：{style}（magazine 或 swiss）
- 内容来源：{content}
- 要求：输出单文件 HTML，包含横向翻页、演讲者模式等完整功能
```

### 调用命令

```bash
claude -p --dangerously-skip-permissions "{prompt}"
```

### 执行流程

1. 读取草稿内容（Markdown）
2. 根据风格选择模板（template.html 或 template-swiss.html）
3. 填充内容，生成主题节奏
4. 输出单文件 HTML 到 `outputs/` 目录

## 依赖

- Node.js 20+
- 首次运行自动安装依赖
