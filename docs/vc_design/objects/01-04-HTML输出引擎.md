# HTML 输出引擎（guizang 那类）

## 描述

把 Markdown 草稿做成"单文件、横向翻页"的网页版演示，是一种输出引擎。

## 属于哪类、叫什么

- 类型：输出引擎
- 引擎名：guizang_ppt，背后是歸藏做的 guizang-ppt 技能

## 两种视觉风格

### 风格一 · 电子杂志 × 电子墨水（默认）

- 有流动质感的背景、衬线大标题配非衬线正文
- 适合：人文分享、行业观察、商业发布这类要"杂志气"的演讲

### 风格二 · 瑞士国际主义

- 极细网格 + 点阵背景、全程无衬线、字号对比强烈
- 高对比的功能色：克莱因蓝 / 柠檬黄 / 柠檬绿 / 安全橙
- 适合：科技产品、数据汇报、设计/工程分享

## 做出来的东西能干什么

- 横向翻页（键盘左右、滚轮、触屏、一键总览）
- 演讲者模式：看当前页/下一页预览、讲稿备注、计时
- 观众屏同步、断线可恢复
- 章节封面、数据大字报、图片网格等版式
- 入场动效、激光笔 / 圈选标注
- 一个文件就是一整套演示，能离线打开

## 进什么、出什么

- 进：一份 Markdown 草稿（来自草稿引擎）
- 出：一个单文件网页演示（样式和脚本都在里面，浏览器直接打开）

## 有哪些参数

- 视觉风格：杂志（默认）或 瑞士
- 主题配色：杂志风、瑞士风各有一套预设色，选了对应风格才有意义
- 目标页数：可以不填，让技能按内容节奏自己定（大致 15 分钟 ≈ 10 页、30 分钟 ≈ 20 页）

> 确切的参数名、取值和约束以契约 `docs/contracts/engine.schema.json` 为准，这里只讲人话。

## 适合 / 不适合

**合适**：线下分享、行业内部讲话、AI 产品发布、需要强烈个人风格的演讲、一次做完不用翻页工具的网页版演示。

**不合适**：大段表格数据和图表叠加、信息密度要求高的培训课件、需要多人协作编辑（它是静态网页）。

## 大致怎么跑

和 pptmaster 引擎是一条路子——都靠 AI 命令行工具跑各自技能，区别只在出来的格式是网页、不是 PPTX。

1. 先把草稿和拼好的提示词落到这个任务自己的目录里。
2. 提示词里写清楚：用哪个技能、要什么风格/主题/篇幅、成品必须落在指定的那一个文件位置，并要求它别中途反问（无人值守要能一口气跑完）、写完照技能自带的脚本自己核一遍。
3. 在这个任务目录下把 AI 拉起来跑，过程中的进度实时记进日志，供前端轮询看。
4. AI 按技能说明自己完成版式选择、主题节奏、动效和演讲者备注，写出那个单文件网页。
5. 引擎看产物到没到位（文件在、是这次跑之后生成的、内容不为空）来判成功还是失败；跑太久会被判超时并终止进程。

## 和 pptmaster 引擎的有意区别

- 两个引擎现在都把产物落在**任务自己的目录**里。早先 pptmaster 会往那份只读的上游技能目录里写产物，已经归位；技能目录是上游只读，绝不往里写。
- 找产物：pptmaster 在任务目录下确定性地找；guizang 直接在钉死的那一个文件上确认，不去跟别的目录混着比新旧。
- 真正的差异只剩"**一页长什么样**"：pptmaster 一页是一个矢量图文件；guizang 是同一个网页里的第几屏。
- 逐页预览：pptmaster 数它那些一页一页的矢量图；guizang 是扫那个网页里有几屏，逐页看时都指向同一个文件、靠"第几屏"定位。

## 技能是怎么被找到的

这个上游技能只有一份技能说明、没有给 agent 的项目说明文件，所以靠 AI 自己发现已安装的技能。部署或首次运行时，把仓库里那份技能链接进 AI 的技能目录（重复跑也不会出问题）；如果用户自己装过同名技能，只提示、不覆盖。提示词里也带着技能的绝对路径，万一链接没成功还能按路径读，不挡任务。

## 跑起来需要什么

- 机器上装好并能用 AI 命令行工具（Claude Code），进程能连上模型
- 装了 Node（技能自带的校验脚本要用）
- 那份上游技能已经拉到本地（子模块已初始化）
- 任务目录可写（技能目录是只读上游，不用可写）
