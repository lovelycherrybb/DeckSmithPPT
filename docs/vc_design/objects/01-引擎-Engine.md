# 引擎

## 描述
系统中的能力组件，负责将输入转化为输出。

## 属性
- 引擎标识
- 显示名称
- 功能描述
- 引擎类型（草稿引擎/输出引擎）
- 参数模式

## 引擎分类

### 草稿引擎
- 职责：将用户上传的文件转化为 Markdown 草稿
- 特点：每次生成新草稿，不累加
- 输入：文件（Word、PDF、链接、文本等）
- 输出：新草稿
- 参数固定：文件列表 + 提示词（可选）

### 输出引擎
- 职责：将 Markdown 内容生成最终展示文件
- 特点：支持多种输出格式
- 输入：选定的草稿版本
- 输出：PPT、HTML 等
- 参数动态：每个引擎不同，前端根据参数模式渲染表单

## 关联关系
- 引擎 → 任务：1对多

## 设计考虑
- 引擎内部可调用 Agent 能力层
- 每种引擎类型可有多种实现
- 新引擎只需实现统一接口即可接入
