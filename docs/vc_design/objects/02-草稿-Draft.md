# 草稿

## 描述
演示文件的内容载体，使用 Markdown 格式。支持多版本管理，可反复修改。

## 属性
- 草稿标识
- 生成任务（哪个草稿引擎任务创建的）
- 版本号（年月日时分秒格式）
- 内容（Markdown 格式）
- 草稿路径（Markdown 文件在服务器上的存储路径）
- 创建时间

## 产生方式

### 文件生成
- 通过草稿引擎将用户文件转化为 Markdown
- 每次生成新草稿（新标识符）
- 版本号为初始版本

### 编辑保存
- 用户手动编辑或 Agent 修改后保存
- 草稿标识符不变，版本号递增
- 同一草稿同一秒内只能有一个版本

## 版本规则
- 版本号格式：年月日时分秒
- 同一秒内不允许保存两次（防止冲突）
- 历史版本不可变，可随时还原
