# 任务

## 描述
引擎的一次工作单元，分为草稿引擎任务和输出引擎任务两种类型。

## 属性
- 任务标识
- 所属项目
- 任务类别（草稿引擎任务/输出引擎任务）
- 使用的引擎
- 引擎任务编号（用于查询 Agent 执行状态）
- 状态
- 状态明细（引擎当前正在做什么）
- 输入参数
- 输出结果
- agent（驱动引擎的 AI agent，如 claude、codex、hermes）
- error（失败/超时原因，仅 failed/timeout 时有值）
- 创建时间、更新时间

## 关联关系
- 项目 → 任务：1对多
- 任务 → 引擎：多对1
- 任务 → 草稿：1对1（草稿引擎任务）
- 任务 → 演示文件：1对1（输出引擎任务）

## 引擎任务编号
- 即 Agent 的会话标识
- 用于查询 Agent 的执行状态和对话历史
- 非 Agent 类引擎可为空

## 状态明细
- 当前状态下引擎正在做什么的描述
- 内容随执行进度变化
- 前端通过轮询获取最新状态

## agent
- 指定使用哪个 AI agent 来驱动引擎
- 可选值：claude、codex、hermes
- 默认值：claude

## error
- 记录任务失败或超时的原因
- 仅在状态为 failed 或 timeout 时有值
- 用于排查问题

## 任务类别

### 草稿引擎任务
- 调用草稿生成引擎
- 输入：用户文件 + 可选提示词
- 输出：新草稿

### 输出引擎任务
- 调用输出引擎
- 输入：选定的草稿版本 + 引擎参数
- 输出：演示文件（PPT、HTML等）
