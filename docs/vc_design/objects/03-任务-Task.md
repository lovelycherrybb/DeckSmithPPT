# 任务

## 描述
引擎的一次工作单元，分为草稿引擎任务、输出引擎任务、修改任务三种类型。

## 属性
- 任务标识
- 所属项目
- 任务类别（草稿引擎任务/输出引擎任务/修改任务）
- 使用的引擎
- 引擎任务编号（用于查询 Agent 执行状态）
- 状态
- 状态明细（引擎当前正在做什么）
- 输入参数
- 输出结果
- agent（驱动引擎的 AI agent，如 claude、codex、hermes）
- error（失败/超时原因，仅 failed/timeout 时有值）
- token 消耗（LLM token 用量，分项 + 派生总数；未上报则为「未记录」）
- 创建时间、更新时间

## 关联关系
- 项目 → 任务：1对多
- 任务 → 引擎：多对1
- 任务 → 草稿：1对1（草稿引擎任务）
- 任务 → 演示文件：1对1（输出引擎任务）
- 任务 → 子演示文件：1对1（修改任务）

## 引擎任务编号
- 即 Agent 的会话标识
- 用于查询 Agent 的执行状态和对话历史
- 非 Agent 类引擎可为空

## 状态明细
- 当前状态下引擎正在做什么的描述
- 内容随执行进度变化
- 前端通过轮询获取最新状态

## agent
- 指定使用哪个 AI agent 来驱动引擎
- 可选值：claude、codex、hermes
- 默认值：claude

## error
- 记录任务失败或超时的原因
- 仅在状态为 failed 或 timeout 时有值
- 用于排查问题

## token 消耗
- 本任务在 LLM 上烧掉的 token，草稿引擎任务与输出引擎任务同口径（详见 ADR-016）
- 记分项四项（新增输入 / 写缓存 / 读缓存 / 输出）加一个派生总数，不合并成单一数字：
  多轮会话里「读缓存」量级远大于新增输入，合并后数字无法解释
- 归集边界：只算该任务的引擎主会话；同一任务断点续跑产生的多次上报按分项累加。
  后端辅助 agent（拟题、草稿改写/编辑）的消耗不混入任务数字
- 未上报时语义为「未记录」，界面如实显示「未记录」：不以 0 呈现，也不做事后估算

## 任务类别

### 草稿引擎任务
- 调用草稿生成引擎
- 输入：用户文件 + 可选提示词
- 输出：新草稿

### 输出引擎任务
- 调用输出引擎
- 输入：选定的草稿版本 + 引擎参数
- 输出：演示文件（PPT、HTML等）

### 修改任务
- 对能逐页编辑的 pptmaster 产物做逐页修改，再在背后重新出一份成品（见 `flows/04-pptmaster修改流程`）
- 输入：一个已有版本（原始演示文件，或任意一个子文件，即"改自哪个版本"，可分叉）+ 改好的逐页内容，或用户的一句修改指令
- 输出：子演示文件（挂在"改自哪个版本"下面，成为它的一个分支）
- **不另造一套**：它和其它任务一样排队、能看进度、失败能重试、也记 token，只是"进去的是某个已有版本、出来的是子文件"
- **能不能改看引擎本事**：只有能逐页编辑的产物才有这种任务，由引擎自己声明、不看引擎名字；HTML 这类产物没有它
- 至于这种任务在引擎那边具体怎么接上，留到定契约时再敲（届时补一篇 ADR）
