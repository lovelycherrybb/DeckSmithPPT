# 项目

## 描述

单个演示文件生成项目，是系统的顶层聚合根。用户首次生成草稿时自动创建。

## 属性

- 项目标识
- 项目名称
- 当前草稿（用户正在编辑的草稿及版本）
- 创建时间、更新时间

## 关联关系

- 项目 → 任务：1对多（任务列表通过 API 返回）

## 生命周期

```
用户首次上传文件 → 草稿引擎任务 → 新草稿 → 项目自动创建
    ↓
可多次：新的草稿引擎任务 → 更多草稿
    ↓
用户选择草稿版本 → 输出引擎任务 → 演示文件
    ↓
可多次：不同参数/引擎 → 不同演示文件
```

## 设计考虑

- 项目是顶层聚合根，管理所有相关任务
- 草稿和演示文件通过任务间接关联到项目
- 支持持续迭代：新增草稿、生成新版本演示文件
