# 演示文件

## 描述
输出引擎任务生成的最终展示文件，如 PPT、HTML 等。

## 属性
- 文件标识
- 生成任务（哪个输出引擎任务创建的）
- 文件名称（默认为"项目名称_文件生成时间戳（年月日时分秒）"）
- 文件格式（PPTX、HTML等）
- 文件路径
- 创建时间

## 关联关系
- 任务 → 演示文件：1对1
- 演示文件 → 子演示文件：1对多（演示文件是版本树的根；子演示文件是通用的派生概念。本轮修改入口只对能逐页编辑的 pptmaster 产物开放，见 `objects/08-子演示文件`、`flows/04-pptmaster修改流程`）

## 设计考虑
- 演示文件由输出引擎任务产生，记录来源便于追溯
- 同一项目可通过多个任务生成多个不同格式的演示文件
- 文件格式决定打开方式（PPT用Office，HTML用浏览器）
- 能逐页编辑的 pptmaster 产物，这一轮可以当作"版本树的根"来改：预览顶部能在"原始文件 / 各个子文件（含分叉）"之间切换，下载时弹框选要哪个版本（每一项是 文件名称 + 生成/保存事件）。子演示文件本身是通用概念，只是别的产物这一轮还没有修改入口，详见 `flows/04-pptmaster修改流程`
