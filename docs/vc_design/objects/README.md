## 核心关系

```
用户（User）← 权限与数据归属主体（三值角色 manager/vip/normal）
└── 项目（Project）← 顶层聚合根（归属某用户；管理员可见全部并显示归属列）
    ├── 草稿引擎任务A → 草稿1（多个版本）
    ├── 草稿引擎任务B → 草稿2（多个版本）
    ├── 输出引擎任务A → 演示文件A（PPTX，pptmaster 产物）
    │        └──（版本树，可分叉）修改任务 → 子演示文件（任一版本都能再往下改、长出新分支）
    │            子演示文件多对一归属演示文件A；每个版本各存各的逐页设计稿和成品
    └── 输出引擎任务B → 演示文件B（HTML，这一轮没有修改入口；子演示文件概念仍然通用）

用户 ──1:1── 用户偏好（默认引擎/页数/自动保存，仅作初始值）
```

> 任务、草稿、演示文件、子演示文件都不单独存归属，一律经所属项目推导（子演示文件走"子 → 演示文件 → 项目"）；项目是唯一的用户级隔离点。

## 引擎架构

```
Agent（能力层，不暴露）
    ↓ 被调用
引擎层
├── 草稿生成引擎：文件 → 新草稿（参数固定）
└── 输出引擎：草稿版本 → 演示文件（参数动态）
```
